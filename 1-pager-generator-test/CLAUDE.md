# Output Rules

## Template precedence

Some source files give a specific template for the output. Follow these rules in order.

1. Check the source file for a specific template.
2. If a specific template exists, fill in that template. Do not apply the
   ASD-STE100 rules below to override the template's format.
3. If no specific template exists, write the output to the ASD-STE100
   standard below.

## Writing standard: ASD-STE100

Write all output to the ASD-STE100 (Simplified Technical English) standard.

- One idea per sentence. Keep sentences short (aim for 20 words or fewer).
- Use active voice. Name the actor: "Run the script," not "The script should be run."
- Use approved, consistent vocabulary. Pick one word per meaning and reuse it —
  do not vary word choice for style (e.g. always "start," never "begin"/"initiate"/"launch"
  for the same action).
- Use words in their one approved sense. Do not use a word as a noun in one place
  and a verb in another (e.g. "test" as noun only, not also as verb, if both appear).
- Avoid strings of nouns stacked as modifiers ("the runbook output review process
  flow"). Rephrase with prepositions ("the process for reviewing runbook output").
- Write procedures as ordered, numbered steps — one action per step.
- Avoid gerunds and complex verb forms where a simple present-tense instruction works.
- Spell out an acronym on first use in a document, then use the acronym consistently.
