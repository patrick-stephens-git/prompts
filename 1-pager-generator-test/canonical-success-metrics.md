# canonical-success-metrics.md

Canonical success metrics reference material. Runbooks read this file to learn which metrics exist. Use these metrics in every analysis and conclusion. Do not redefine them. Do not replace them with approximations.

---

## Predefined Metrics & Definitions

### Success Metrics
- Conversion Rate (CVR)
- Average Order Value (AOV)
- Units per Transaction (UPT)
- Revenue per Visit ($/Visit)
- Revenue
- Profit
- Lifetime Value
- Loyalty
- Athlete CSAT
- Teammate Job Enablement CSAT

### Engagement Metrics
- Clicks
- Click-through Rate (CTR)
- Product Detail Page Views (PDP Views)
- PDP Bounce Rate
- Add-to-Cart Rate

### Guardrail Metrics
- Relevance
- Latency
- Model Coverage
- Site Performance
- Average Unit Retail (AUR)
